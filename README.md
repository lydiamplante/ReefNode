A Raspberry Pi-based monitoring and automation system being actively developed for saltwater aquarium projects.

CURRENT PHASE OBJECTIVES:

- Simulate changing conditions in the areas of air temperature/humidity, water temperature, and water level
- Create a visual output summary of conditions as well as simulated actuators (heater/fan, ATO)
- Prepare a basic layout in which sensors can be implemented once they are acquired
- Start early system calibration experiments with a DHT22/AM2302 temperature/humidity sensor
